# 项目使用

DSH FreeCanvas 可用于私有化部署、二次开发、模型渠道接入，以及 AI 图片、视频和文本工作流。

## 适合的使用方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 技术支持、交付咨询或联合方案评估。

MIT 协议允许免费商用，无需购买商业授权。

公开的产品建议和可复现技术问题可提交至 GitHub Issues。请勿在 Issue 中发布商业机密或安全漏洞细节。
