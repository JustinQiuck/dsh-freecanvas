# MIT 开源协议

DSH FreeCanvas 采用 [MIT License](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/LICENSE)，并保留源项目版权声明。任何个人、团队和企业都可以免费、自由地使用本项目，没有使用场景和商业用途限制。

## 项目初衷

DSH FreeCanvas 保持开源，希望让用户接入自己的 API 与模型渠道，用画布组织提示词、参考图、素材和生成结果，搭建适合 DSH 的 AI 创作工作流。


## 你可以做什么

- 免费使用、复制和修改代码。
- 发布原版或修改后的版本。
- 将项目用于商业产品、内部系统、私有化交付或在线服务。
- 将项目代码合并到开源或闭源软件中。
- 对项目或修改后的版本再授权或销售。

你不需要购买商业授权，也不需要公开自己的修改或业务代码。
